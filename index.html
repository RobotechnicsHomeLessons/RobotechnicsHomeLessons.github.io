Те же задачи, но через if

Задачи те же, что в ДЗ «Кнопки и светодиоды» ниже, а решаем их по-новому: с помощью if и else. Как должны гореть светодиоды, вы уже знаете: анимация та же.

кнопка → D3, D4 светодиоды → D5, D7, D8, D9, D10

Как устроен if:

if (условие) { что сделать } else { что сделать иначе }

if (digitalRead(4)) значит «если кнопка на D4 нажата».

Пример: задание 1 через if
// Кнопка на D4 включает светодиод на D8 - теперь через if.

void setup() {
  pinMode(4, INPUT);    // кнопка - вход
  pinMode(8, OUTPUT);   // светодиод - выход
}

void loop() {
  if (digitalRead(4)) {           // ЕСЛИ кнопка нажата
    digitalWrite(8, HIGH);        // включить светодиод
  } else {                        // ИНАЧЕ
    digitalWrite(8, LOW);         // выключить светодиод
  }
}

1Одна кнопка — один светодиод

Кнопка на D4 включает светодиод на D8. Загрузите пример выше и разберитесь, какая строка за что отвечает.

2Одна кнопка — два светодиода

Кнопка на D4 включает светодиоды на D8 и D9.

Подсказка: внутри фигурных скобок { } может быть сколько угодно команд.

3Две кнопки

Кнопка на D4 включает D8 и D9, а кнопка на D3 включает D8.

Подвох: если для каждой кнопки написать свой if-else, то else второй кнопки погасит D8, который включила первая. Подсказка: в начале loop() выключите все светодиоды, а потом для каждой кнопки напишите if без else, который только включает.

4Две кнопки, общий светодиод

Кнопка на D4 включает D8 и D9, а кнопка на D3 включает D8 и D7.

Кнопка на D4 включает светодиоды на D8, D9 и D10.

6 ★Пять светодиодов

Кнопка на D4 включает D8, D9 и D10, а кнопка на D3 включает D5 и D7.

Кнопки и светодиоды

На занятии мы сделали две кнопки и три светодиода. Теперь меняем, какая кнопка какие светодиоды включает. Светодиод горит, пока кнопка нажата.

кнопка → D3, D4 светодиоды → D5, D7, D8, D9, D10
В коде номер пина пишется без буквы: D8 на плате — это 8 в программе.

Анимация показывает, что должно получиться. Кнопки можно нажимать самим: зажмите кнопку, и светодиоды загорятся.

1Одна кнопка — один светодиод

Кнопка на D4 включает светодиод на D8. Начните с кода для начала.

2Одна кнопка — два светодиода

Кнопка на D4 включает светодиоды на D8 и D9.

3Две кнопки

Кнопка на D4 включает D8 и D9, а кнопка на D3 включает D8.

Подвох: обе кнопки управляют светодиодом D8. Если одна кнопка его включает, а другая тут же выключает, он будет мерцать или не загорится. Подсказка: в начале loop() выключите все светодиоды, а потом включите только те, чьи кнопки нажаты.

4Две кнопки, общий светодиод

Кнопка на D4 включает D8 и D9, а кнопка на D3 включает D8 и D7.

5 ★Три светодиода

Кнопка на D4 включает светодиоды на D8, D9 и D10.

6 ★Пять светодиодов

Кнопка на D4 включает D8, D9 и D10, а кнопка на D3 включает D5 и D7.

 }

Программа 6: переключение состояния по сигналу
bool state = true;

void setup() {
  pinMode(4, INPUT);
  pinMode(8, OUTPUT);
  
}

void loop() {
  if (digitalRead(4)) {
    delay(200);
    state = !state;
  }

  digitalWrite(8, state);
}
Программа 7: переключение состояния по сигналу
bool state = true;

void setup() {
  pinMode(4, INPUT_PULLUP);  // кнопка без резистора: нажата = LOW
  pinMode(8, OUTPUT);
  
}

void loop() {
  if (!digitalRead(4)) {   // ! значит "наоборот": с INPUT_PULLUP нажатая кнопка даёт 0
    delay(200);
    state = !state;
  }

  digitalWrite(8, state);
}
Программа 8: мигание светодиодом

void setup() {
  pinMode(8, OUTPUT);
  pinMode(9, OUTPUT);
  pinMode(10, OUTPUT);
}

void loop() {
  digitalWrite(8, 1);
  delay(500);
  digitalWrite(8, 0);

  digitalWrite(9, 1);
  delay(500);
  digitalWrite(9, 0);

  digitalWrite(10, 1);
  delay(500);
  digitalWrite(10, 0);
}

Важно: программы загружаются по одной. Во всех программах кнопка на D4, светодиоды на D8, D9 и D10 — как в заданиях. Для кнопки используйте корректную схему подключения и не оставляйте вход «в воздухе» — иначе его состояние может считываться нестабильно.

Код 1: три светодиода

tri_svetodioda.ino
// ДОМАШНЕЕ ЗАДАНИЕ. Код 1: три светодиода
// Сейчас все три светодиода мигают ОДНОВРЕМЕННО.
// Ваша задача: менять только то, что внутри loop().

// --- Названия придумали МЫ сами. Можно назвать как угодно. ---
// Здесь запоминаем, к какому пину подключён каждый светодиод.
int led1 = 3;   // первый светодиод на пине 3
int led2 = 6;   // второй светодиод на пине 6
int led3 = 9;   // третий светодиод на пине 9

// setup() выполняется ОДИН раз при включении платы.
// setup, loop, pinMode, digitalWrite, delay - это СИСТЕМНЫЕ слова, их менять нельзя.
void setup() {
  pinMode(led1, OUTPUT);   // пин 3 будет ВЫДАВАТЬ сигнал
  pinMode(led2, OUTPUT);   // пин 6 будет ВЫДАВАТЬ сигнал
  pinMode(led3, OUTPUT);   // пин 9 будет ВЫДАВАТЬ сигнал
}

// loop() повторяется по кругу бесконечно.
void loop() {
  // digitalWrite(КУДА, ЧТО СДЕЛАТЬ)
  // HIGH - включить, LOW - выключить

  // Включаем все три
  digitalWrite(led1, HIGH);
  digitalWrite(led2, HIGH);
  digitalWrite(led3, HIGH);
  delay(500);   // ждём 500 миллисекунд (полсекунды)

  // Выключаем все три
  digitalWrite(led1, LOW);
  digitalWrite(led2, LOW);
  digitalWrite(led3, LOW);
  delay(500);   // ждём полсекунды
}

Код для начала: кнопка D4 → светодиод D8

knopka_svetodiod.ino
// Кнопка на D4 включает светодиод на D8 (это задание 1).
// Светодиод горит, пока кнопка нажата.

// Названия придумали МЫ сами
int button = 4;   // кнопка на пине D4
int led = 8;      // светодиод на пине D8

void setup() {
  pinMode(button, INPUT);   // кнопка - ВХОД, плата читает её
  pinMode(led, OUTPUT);     // светодиод - ВЫХОД, плата им управляет
}

void loop() {
  // digitalRead(ОТКУДА) - читаем кнопку: 1 нажата, 0 не нажата
  int state = digitalRead(button);

  // digitalWrite(КУДА, ЧТО СДЕЛАТЬ) - отдаём светодиоду то, что прочитали
  digitalWrite(led, state);
}

// Если светодиод горит, когда кнопка НЕ нажата,
// напишите !state вместо state. ! значит "наоборот".

// ДОМАШНЕЕ ЗАДАНИЕ. Код 2: датчик света
// Плата читает датчик и пишет число на экран компьютера.
// Цифровое значение - это только 0 или 1: свет есть или света нет.

// Здесь запоминаем, к какому пину подключён датчик.
// Переподключили датчик на другой пин - поменяйте число здесь!
int sensorPin = 2;

void setup() {
  pinMode(sensorPin, INPUT);   // пин будет ПРИНИМАТЬ сигнал (вход)
  Serial.begin(9600);          // включаем связь с компьютером
}

void loop() {
  // digitalRead(ОТКУДА) - прочитать, что сейчас на пине: 0 или 1
  int value = digitalRead(sensorPin);

  Serial.println(value);   // написать число на экран
  delay(200);              // ждём 0,2 секунды и читаем снова
}
